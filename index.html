Zakaria Design Project Assistant

A personal project discovery and bidding assistant being developed by Zakaria Abu Hweidi, a graphic and UI/UX designer.

Planned features

  • Find relevant graphic design and UI/UX projects.
  • Filter opportunities by skills and budget.
  • Generate proposal drafts based on actual experience.
  • Configure bid amounts and delivery times.
  • Support manual approval and, if authorized, automatic bid submission through the official API.

Intended use

This application is intended only for the developer's own Freelancer.com account. It is not offered as a public service. API access and automated bidding are subject to Freelancer.com's approval, permissions, and applicable limits.

About this website

This is an informational page. It does not request account passwords or API tokens and does not connect to Freelancer.com.
